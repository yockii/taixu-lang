# macOS 的单次内存申请上限

macOS 普通运行时的页适配器将物理内存的 4 倍作为单次取页上限。超过时按内存不足结束：标准错误输出
`taixu: 内存不足`，退出码 3。该上限包含分配器的块头与页对齐开销，并非 `Bytes` 数据长度的精确上限。
无法取得物理内存大小或计算上限会溢出时，只由系统的内存映射调用判定申请是否成功。

这个上限不预留物理内存，也不累计进程的全部申请。允许过量提交的系统仍可能在随后触页时终止进程，此时运行时无法输出
内存不足诊断。`--heap-check` 使用独立的测试页堆及其测试上限，不经过普通页适配器。

`bytesNew` 的结果仍全部为零。大块由匿名映射或分配器清零后交出，省去重复清零，避免仅为创建零缓冲而立即触碰整段内存；
小块从空闲链复用时仍清零。
