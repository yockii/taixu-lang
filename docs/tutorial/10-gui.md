# 10 GUI 现状

**本章说明**：0.3.0-beta.1 里桌面 GUI 处于迁移空窗期——这一版能做什么、
不能做什么。

GUI 在太虚里是**外部库**，不进语言核心。它的绘制与窗口引擎
正在迁移到新的实现上，因此在这一版里：

- **不随包**：发布包里没有 GUI 框架，`examples/` 里也没有 GUI 样例；
- **没有 GUI 模板**：`taixu init` 只有 `console` 与 `library` 两个模板，
  `taixu init gui …` 不可用；
- **旧的 GUI 教学内容已撤下**：早期教程里的窗口程序、事件重放与画面定格
  等用法（`--replay`、`--frame`、`--auto` 等选项）在这一版里都不可用。

这一版专注于命令行程序与库：语言本身、标准库、`build` 生成的单文件可执行
程序、LSP／DAP／MCP 工具链都完整可用。迁移完成后，GUI 会作为外部库重新
提供，届时本章会改回入门教程。

需要提前做实验的读者，可以用语言的外部函数接口（`declare function … from
"库"`）直接调用操作系统的界面 API，规则见语言规范
[§6.8 外部函数与原生 FFI](../design/D3-s1-language-spec-v0.42.md)；这条路
不在本教程范围内。

本书的事件订阅（07 章 `std/events`）与确定性调度（08 章）不依赖 GUI，
照常可用。
